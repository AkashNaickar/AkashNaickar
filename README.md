* Contributor to **[Biome](https://github.com/biomejs/biome)** — implemented the `noExtendNative` nursery lint rule in Rust to prevent prototype pollution (**[PR #11136](https://github.com/biomejs/biome/pull/11136)**)
* Creator of **[TrumorGPT](https://github.com/AkashNaickar/TrumorGPT)** — Graph-Based Retrieval-Augmented Generation (GraphRAG) for real-time rumor detection and claim verification
* Creator of **[Kepa](https://github.com/AkashNaickar/Kepa)** — a persistent memory layer for AI coding agents powered by CockroachDB vector search + MCP
* Contributor to **[Meshery](https://github.com/meshery-extensions/meshery-mcp-server)** — authored the Go module scaffold and CI test pipeline for the Meshery MCP Server (**[PR #28](https://github.com/meshery-extensions/meshery-mcp-server/pull/28)**)
* Contributor to **[LiteLLM](https://github.com/BerriAI/litellm)**, **[PDFio](https://github.com/michaelrsweet/pdfio)**, and **[TTF](https://github.com/michaelrsweet/ttf)** across AI routing gateways and low-level C libraries.
